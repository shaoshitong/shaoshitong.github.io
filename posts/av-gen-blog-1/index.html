一、三分钟看懂音视频生成的「三代跃迁」

很多人刚接触音视频生成时会被满屏的名词吓到：DiT、3D-VAE、Flow Matching、DMD2、GRPO、MoE、Ulysses 并行……其实只要顺着「痛点驱动演进」的脉络来看，所有技术发明都是为了解决上一个时代最要命的问题：

发展阶段 代表系统 / 论文 核心技术范式 一眼能看出的特征与瓶颈
1.0 默片拼接期
(2022–2023)		 AnimateDiff、ModelScope、SVD、VideoLDM 2D 文生图 UNet + 临时外挂的 1D 时间注意力层（Temporal Layer） 像「会轻微晃动的动图」；物体转个身就变脸，手脚和物理规律基本靠蒙，完全没有声音。
2.0 时空统一期
(2024–2025 上)		 Sora、MovieGen、CogVideoX、HunyuanVideo、Wan 2.1 3D Causal VAE + DiT / MMDiT + Rectified Flow + Dense Captioning 画面终于有了真实世界的空间连贯性和复杂运镜，但还是「默片」，算力开销大，50 步推理慢如蜗牛。
3.0 原生音画与智能体期
(2025 下–2026)		 Veo 3/3.1、Sora 2、LTX-2.5、Wan 2.2/3.0 (MoE)、Ovi、MiniMax H3 (MMX-H3) 音画单次联合去噪、MoE 专家分工、Flow-GRPO 物理对齐、4 步蒸馏、LLM 导演 Agent 一次生成画面 + 对白口型 + 环境拟音 + BGM；配合 Qwen-Image 和 LLM 智能体，直接产出多镜头连贯短片。
