Chapter 06 · 五段式训练 Pretrain → Midtrain → SFT Flow-GRPO & DMD2 / MeanFlow 蒸馏

多阶段训练全链路：Pretrain → Midtrain → SFT → RL → 蒸馏

你不可能把一个刚出生的婴儿直接扔进好莱坞片场让他拍 4K 电影。现代音视频大模型也一样——今天所有的顶级模型（Veo 3、Sora 2、Wan 2.2、HunyuanVideo、Seedance）都彻底吸收了 LLM 的「多阶段培养体系」，演化出标准的五段式炼丹流水线：从通识教育、拔高特训、美学精修、赏罚分明的强化学习，一直到最后的极速步数蒸馏。

现代音视频大模型「五段式培养路线图」 数据量递减 · 质量与单步收益递增

一、Stage 1：Pretrain（海量低分预训练）

这一阶段烧掉全流程 60%–70% 的算力，目标只有一个：用最高吞吐量把整个世界的视觉、运动与声音常识塞进模型参数里。

  • 为什么现在全用 Flow Matching（流匹配）而不是老 DDPM？ 用大白话说，DDPM 像走弯弯曲曲的山路把噪声一点点还原成画面；而 Rectified Flow / Flow Matching 直接在纯噪声 x₁ 和真实视频 x₀ 之间拉一条笔直的高速公路（xₜ = (1-t)x₀ + t·x₁），让模型直接预测恒定速度场 v = x₁ - x₀。路直了，训练更稳，推理步数也能天然砍半！
  • 渐进式分辨率（Progressive Resolution）：从 256p / 360p 短片段（2–4 秒）起步，此时每条视频只有几千个 Token，可以在几千张卡上以极高吞吐量过几亿条图文视频，等语义对齐和基础运动规律学稳了，再升到 480p。
  • Logit-Normal 时间步采样：不要均匀采样噪声时间步 t！研究发现 t=0 附近太简单、t=1 附近太难，最有学习价值的是中间噪声区（t ≈ 0.3–0.7），采用 Logit-Normal 分布把算力重点砸在中间段，收敛速度肉眼可见提升。

二、Stage 2：Midtrain（退火、长时长与高分扩展）

很多团队以前直接从 Pretrain 跳到 SFT，结果发现高分辨率崩坏、视频超过 5 秒就开始画面发黄/漂移。借鉴 LLM（如 DeepSeek / Qwen）的成功经验，2025 年之后工业界普遍把 Midtrain（中期继续预训练） 单独拎出来作为一个关键阶段：

  1. 数据质量大换血：踢掉普通网图与低分视频，把图片占比从 50% 骤降到 15% 以下，全面换成 720p/1080p、长时长（8–15 秒）、高运动幅度、强原声同步的 Top 15% 数据。
  2. Context 长度外推：把 3D-RoPE 的时间与空间基频用 YaRN / NTK-Aware 策略平滑扩展，同时用 Flow Shift（时间步偏移）把噪声分布往高噪端微调——因为高分辨率像素间冗余度高，需要更强的噪声才能真正破坏整体结构！
  3. WSD 学习率退火（Warmup-Stable-Decay）：在高质量数据上把学习率平滑降下来（Annealing），这一步往往能让画质和物理稳定性发生「脱胎换骨」的质变。

三、Stage 3：SFT（精选美学与多任务指令精调）

Midtrain 结束时，模型已经很强，但画风还有点「素颜记录片」的感觉，不够电影感，或者对 I2V（图生视频）、首尾帧插值、多图参考（Omni-Ref）等具体产品形态还不够顺手。

SFT 阶段只需要几万到几十万条人类审美专家精挑细选的 Top 1% 电影级片段（构图绝美、光影讲究、无任何瑕疵、音画极度干净）+ 人工精细核对过的 Dense Caption。几千个 Step 跑完，模型的「出片质感」会瞬间从手机随手拍跃升到好莱坞大片，同时学会严格遵守首帧锁脸、运镜指令和特定画风。

四、Stage 4：RL 后训练（DPO → Flow-GRPO / DanceGRPO）

SFT 已经很美了，为什么 2025–2026 年所有头部实验室都在疯狂卷 Video RL（视频强化学习）？

因为 SFT 用的依然是像素/潜空间的 MSE 监督 Loss——它只告诉模型「照着标准答案抄」，但从没严厉惩罚过「多长出一根手指」「杯子穿过桌子」「人嘴没张却发出声音」「忽略了 Prompt 里的第三个条件」！在 MSE 眼里，多一根手指只占整段视频 0.01% 的像素误差，微不足道；但在人类眼里，这就是 0 分废片！

🚀 2025–2026 爆火范式：Flow-GRPO 与 DanceGRPO 是怎么把 RL 搬进视频生成的？

传统的 Flow Matching 采样是确定性的 ODE（常微分方程），同一个初始噪声永远走出同一条路，根本没法像 LLM 那样「随机探索不同答案」来做强化学习。Flow-GRPO / DanceGRPO 用了三招神来之笔彻底打通了这条路：

  1. ODE → SDE 转换：在 RL Rollout 采样时，临时把确定性 ODE 改写成数学上边缘分布完全等价的随机微分方程（SDE），在每一步注入可控随机扰动，让模型针对同一个 Prompt 探索出 G = 8 ~ 16 条各不相同的生成视频！
  2. 多维裁判团打分（Multi-Reward Ensemble）：不再只看一个分数，而是同时给这组视频打五个维度的分——① VLM 指令遵循分（有没有漏画元素）、② 物理合理性与防畸变分（手脚/重力/穿模）、③ 运动自然度与流畅分、④ 人类美学偏好分、⑤ 音画与口型同步分（SyncNet / PE-AV）。
  3. 组内相对优势更新（Group Relative Advantage）：不需要额外训一个占满显存的 Critic 价值网络！直接把这组 G 个视频的得分减去组内均值、除以标准差，好于平均的视频狠狠奖励，差于平均的狠狠压制，再加一点 KL 散度约束防止「刷分作弊（Reward Hacking，比如把画面饱和度拉爆来骗美学分）」。

五、Stage 5：步数与 CFG 蒸馏（把 100 次计算压到 4 次！）

经过前四关，你的教师模型（Teacher）画质、物理、音画都无敌了——唯一的问题是太慢了：推理一条 5 秒 720p 视频需要 50 步采样，加上 CFG（Classifier-Free Guidance，每步要算一次有条件 + 一次无条件），一共要做 100 次巨大的 DiT 前向计算！商用成本根本扛不住。

于是最后一关 Distillation（步数蒸馏） 登场。它的目标是用极少的步数（4 步、2 步甚至 1 步）且去掉 CFG 双倍开销，逼出与 50 步教师模型肉眼难辨的画质！目前主流有三大技术流派：

蒸馏流派 代表算法 大白话原理解析 工业界实测评价
分布匹配蒸馏
(主流王者)		 DMD / DMD2 / BiDMD / PDMD / TDM 不强求学生一步步死抄教师的像素轨迹（否则容易糊），而是同时维护一个「真教师分数网络」和一个「假学生分数网络」，用 KL 散度梯度（+ 可选 GAN 判别器）逼迫学生 4 步生成的整体分布与教师 50 步分布完全重合！ 4 步出片最锐利、细节最像大片，甚至经常比原版教师更有对比度，是当前视频蒸馏第一主力（Wan / Hunyuan / Seedance 等广泛采用）。
平均速度流
(学术新星)		 MeanFlow / Decoupled MeanFlow 普通 Flow Matching 学的是「瞬时速度」，所以必须切 50 小步积分；MeanFlow 直接通过恒等式让网络学从时间 r 到 t 的「平均速度（Average Velocity）」，一步跨过去就等于积分！ 数学极其优雅，不需要同时在显存里塞 3 个大模型（Teacher + Fake + Generator），1–4 步扩展潜力巨大。
一致性 / 渐进蒸馏 LCM / PCM / Progressive Distillation 让轨迹上任意时间点都直接指向同一个终点 x₀，或把步数 64 → 32 → 16 → 8 → 4 逐级折半。 训练稳定，但压到 4 步以下时画面容易发灰、发糊、缺乏高频质感，常作为 DMD 的热身初始化阶段。
💡 顺手白嫖 2× 加速：CFG 蒸馏（Guidance Distillation）

几乎所有蒸馏框架都会顺手把 CFG Scale（比如 w = 5.0） 烘焙进学生模型里：教师计算目标时用带 CFG 的速度场 v_cfg = v_uncond + w · (v_cond - v_uncond)，而学生推理时只算 1 次条件前向就能直接输出带强引导的结果。50 步×2（100 NFE）→ 4 步×1（4 NFE），直接带来 25 倍推理加速！
