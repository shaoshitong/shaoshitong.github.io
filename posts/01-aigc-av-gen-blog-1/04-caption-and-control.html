Chapter 04 · 标注与可控性 Dense Captioning 精确控制方法论

什么是 Caption？如何精确控制视频？什么样的 Caption 才是好的？

OpenAI 在 DALL·E 3 和 Sora 技术报告里揭示了一条价值十亿美元的行业秘密：决定生成模型到底「听不听话」的第一杠杆，不是魔改 Attention，而是 Caption（数据标注文本）的质量！ 这一章我们彻底把三个核心问题讲透：Caption 到底在教模型什么？什么标准才算顶级的音视频 Caption？除了写文字，工业界还有哪些精确控制视频的「硬手段」？

一、说人话：什么是 Caption？为什么「短标签」会让模型变聋？

Caption（视频/音视频描述文本），就是训练阶段配在每一段视频旁边的「文字说明书」。

想象一下，你给一个学画画的孩子看 1000 段完全不同的猫视频——有的猫在沙发上睡觉、有的猫在雪地里打滚、有的镜头从头顶俯拍、有的慢镜头特写猫爪——但你在每段视频下面只写了一句懒人标签："a cat"。

结果会发生什么？模型会彻底学会「忽略控制」！因为无论视频里是晴天还是雨天、俯拍还是跟拍、喵喵叫还是呼噜声，标签全都是 "a cat"，模型被迫把所有变化都塞进随机噪声里去「抽盲盒」。等你推理时想精确控制「镜头左移、逆光特写、猫轻轻叫了一声」，模型根本听不懂，因为它训练时压根没建立起「这些词 ↔ 对应画面/声音变化」的因果映射！

🧠 Caption 的第一性原理

「你在 Caption 里写清楚了什么，模型就只能听懂什么；你在 Caption 里漏掉了什么，模型就永远只能靠随机噪声瞎蒙。」
这就是为什么现代视频大模型（Sora、MovieGen、HunyuanVideo、Wan、Veo 3）全部抛弃了原始网页标题，花巨资用专门微调的多模态大模型把全库视频重新写了一遍 Dense Caption（密集详尽标注）。

二、什么样的 Caption 才是「好的 Caption」？—— 六维黄金标准

并不是字数越长越好！流水账、文艺抒情、或者 VLM 瞎编的幻觉词，反而会毒害模型。工业界公认的顶级音视频 Dense Caption 必须同时满足下面这六个维度（6D Standard）：

1. 主体与外观锚定（Subject & Visual Anchor）

精准描述核心人物/物体的数量、性别/年龄、衣着材质、颜色、显著特征及初始空间位置（如「画面左侧穿着深棕色皮夹克、留着橘红色齐肩发的年轻女性」）。

2. 动作与时间先后（Temporal Action Sequence）

视频是时间的艺术！必须用明确的时序连接词（起初 → 随后 → 紧接着 → 最后）写清动作的起承转合、幅度快慢与因果关系，绝不能只写静态画面。

3. 镜头语言与运镜（Camera & Framing）

景别（特写 Close-up / 中景 Medium / 全景 Wide）、机位角度（低机位仰拍 / 俯拍 / 过肩）、运镜方式（固定机位 Static / 推轨 Push-in / 左摇 Pan Left / 环绕 Orbit / 手持微晃）。

4. 场景、光影与视觉风格（Lighting & Style）

环境背景、天气时段、光源方向（暖色逆光、霓虹侧光、柔光箱）、景深虚化、色彩基调以及画风（写实电影胶片 / 3D 动画 / 赛博朋克 / 纪录片手持）。

5. 物理互动与微细节（Physics & Micro-dynamics）

风吹动头发的方向、雨水打在玻璃上的滑落、倒影、烟雾弥散、布料褶皱与重力反馈——这些细节是把「AI 塑料味」变成「真实世界模拟器」的关键。

6. 原生音频分层标注（Audio & Dialogue Track）

音视频一体模型的核心！必须把声音拆成三层写清楚：① 精确台词与说话人情绪/音色（带起止时机）、② 同步拟音 Foley（脚步声、碰撞声）、③ 环境底噪与背景音乐。

三、大规模 Recaption 工程里的三大「隐形杀手」

  1. VLM 幻觉（Hallucination）：开源 VLM 经常「脑补」画面里根本没有的动作（比如画面里人只是站着，VLM 瞎写「他挥手致意并转身离开」）。解法是采用 多专家解耦标注流水线：视觉 VLM 负责主体/场景，专用运镜分类器/光流模型负责运镜标签，Whisper/ASR 负责精确对白转录，Audio Captioner（如 Qwen2-Audio）负责拟音与环境声，最后再由一个严格受约束的 LLM 融合成通顺段落并做一致性核验！
  2. 格式单一导致过拟合：如果所有训练集 Caption 全都以 "In this video, we can see..." 开头，模型就会对固定句式过拟合。工业界都会做多粒度混合标注（短/中/长 + 结构化/自然语言混合），并按一定概率（如 10%）随机 Drop 掉文本做 CFG（Classifier-Free Guidance）训练。
  3. 中英文语义对齐：如果底座 Text Encoder 用了双语强的模型（如 Qwen-VL / umT5 / Qwen3），训练时混入一定比例高质量中文 Caption，能避免中文用户提示词经过翻译损失成语、古风、本土文化细节。

四、只靠文字还不够：如何「精确控制」视频？

哪怕 Caption 写到 500 字，文字天生是「低带宽、离散的」——你很难只用文字精确规定「第 1.3 秒杯子向右平移 12 厘米，同时镜头绕桌旋转 35 度，且主角长相和上一场戏一模一样」。因此，现代音视频生成建立了一套五层递进的精确控制体系：

控制层级 核心技术方案 能精准控制什么？ 典型代表模型 / 工作流
L1 文本与脚本控制 Dense Caption + PE 改写 + 结构化时间轴/对白标记（如 <S>...<E>） 剧情走向、情绪氛围、对白内容、基础运镜与声音类型 Veo 3、Ovi、Sora 2、HunyuanVideo
L2 首帧 / 尾帧 / 关键帧锚定 I2V、First-Last Frame（首尾帧插值）、Keyframe Conditioning 精确锁定起止构图、光影、人物外观，保证镜头衔接丝滑 Wan 2.2 I2V、Kling、MMX-H3、LTX-2.5
L3 多主体一致（Omni-Reference） 多图参考注入（人+衣+景+道具拼接进 Context Token） 跨镜头保持同一主角脸型/服饰/场景绝对不崩（拍剧核心！） MiniMax H3 (Omni-Ref)、Vidu Q1、Kling Multi-Ref、Phantom
L4 空间与运镜几何控制 CameraCtrl / Plücker Ray 相机外参、Motion Brush 运动轨迹、Depth/Pose/Canny ControlNet 像素级指定物体移动路线、精确 3D 相机轨迹、舞蹈骨骼动作 CameraCtrl、Tora、Wan-VACE、UniAnimate

🎯 实战心法：如何组合使用这些控制手段？

不要指望靠写一篇 800 字的「小作文」解决所有可控性问题！工业界最稳的做法是「图文锁外观（L2/L3）+ 几何/首尾帧锁运动（L2/L4）+ 精炼 Dense Caption 锁剧情与声音（L1）」。这也是为什么第 9 章的 LLM → Qwen-Image → MMX-H3 智能体流水线能拍出商业级短片的核心秘诀！
